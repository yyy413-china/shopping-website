# shopping‑website
电商购物网站，基于 Vue + SpringBoot 的前后端分离课程实践项目

## 项目介绍
本购物网站是全栈课程实践项目，后端使用SpringBoot + MyBatis实现业务接口，操作MySQL数据库；前端采用Vue实现页面交互。实现商品浏览、购物车、订单管理等基础电商功能。

## 技术栈
- 后端：SpringBoot、MyBatis、Maven、Java
- 数据库：MySQL
- 前端：Vue

## 项目功能
1. 商品列表浏览
2. 加入购物车
3. 生成订单
4. 用户基础操作

## 运行方式
> 本项目为本地课程项目，未部署公网服务器，需要在本地IDEA中运行。
1. 使用MySQL执行仓库内提供的sql脚本，完成数据库建表。
2. 使用IDEA导入后端SpringBoot项目，修改application配置文件中的数据库账号密码为自己本地环境。
3. 启动SpringBoot后端服务。
4. 搭配Vue前端项目进行访问。
